
# AccessoryAura

A responsive fashion accessories website built with HTML and CSS.

## Features
- Cream-and-brown theme
- Handbags, jewellery, watches, and sunglasses
- Product cards and prices
- About and contact sections
- Responsive layout

## Docker
Build: `docker build -t accessoryaura .`

Run: `docker run -d --name accessoryaura-container -p 8084:80 accessoryaura`
